# Models

The practical reader uses `runtime.json` and the included 1.3 MB `cnn_diverse.pt`; retrain with `python -m src.train_diverse` if desired. Older trained files are present locally but ignored by Git. `selection.json` preserves the original validation-only experiment winner, `cnn_lr_low.pt`. `docs/results/<name>.json` contains preprocessing and training configuration. PyTorch state dictionaries load with weights_only=True. Joblib artifacts must come from trusted local training. The official pretrained download is cached under models/cache and is not committed. See SETUP.md for both build paths.
